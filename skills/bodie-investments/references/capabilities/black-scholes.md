# 给无股息股票的欧式期权定价

## R — 来源

第 21 章 §21.4–21.5，式 21.1 与例 21.4（PDF 第 759–761 页）。例题可用作标准正态函数和年化口径的交叉检查。

## I — 原理

在恒定利率、恒定波动率和可连续调整复制组合等假设下，欧式权利的模型价值取决于现价、行权价、期限、波动率及无风险利率。预期股票收益率无需作为输入。

## A1 — 原书算例复核

例 21.4 给定现价 100、行权价 95、剩余四分之一年、连续年利率 10%、年化波动率 50%。保留中间精度得到 d₁≈0.43017、d₂≈0.18017，看涨价值 13.69527，四舍五入为原书的 13.70。

## A2 — 何时调用

已给出欧式合约条件并需估值，或要解释波动率上调对模型价的影响时使用。只有到期现价情景并询问损益时，直接计算到期给付，另计权利金。

## E — 操作与验收

1. 记录 S、K、剩余年数 T、连续复利年率 r 和年化波动率 σ，核对标的在此期间的分红安排。若给有效年率 i，先换为 ln(1+i)。
2. S、K、σ、T 均为正时，算 d₁=[ln(S/K)+(r+σ²/2)T]/(σ√T)，d₂=d₁−σ√T。令 N 为标准正态累积分布。
3. 报告每份标的的 C=S·N(d₁)−K·exp(−rT)·N(d₂)。同条款看跌 P=C+K·exp(−rT)−S。合约总价值再乘合约乘数。
4. 检查 max(0,S−K·exp(−rT)) ≤ C ≤ S；若改变波动率，固定其余参数重算。模型价与市价并列时，给出分红、波动率或交易摩擦可能造成的差额。

## B — 边界

T=0 时用到期给付，σ=0 时用确定性折现给付。美式看跌存在提前行权选择，有离散分红时须另建股息时间表；两种情形都需要重新选模型。
