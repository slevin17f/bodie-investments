# 按本币重算海外收益与分散效果

## R — 来源

第25章 25.2、25.3、25.4，印刷页871–873、882、885起。

## I — 方法

把外地资产的增长和汇率变动放在同一条现金流上。各资产先转入同一币种和期间，再估计组合分散效果。

## A1 — 演算

教材例25.1的金额复核。美元14,000按1.40美元/英镑兑换，英镑资产增长10%，按1.20换回得13,200美元。收益为−800/14,000≈−5.71%；该页正文写作−4%，与金额及次页式25.1不一致。

## A2 — 调用条件

用于外国市场涨了但本币账户亏损、汇率贡献、跨国相关性或比较套保与裸露头寸。

## E — 操作与输出

1. 指定本币、外币，E 表示一单位外币的本币价。反向报价先求倒数；本地收益包含同一期间分配。
2. 本币增长=(1+r_local)E₁/E₀。分解为本地收益、汇率收益和两者乘积；以起始资金换汇、投资、换回复算。中间分配若不再投资，按各自换汇日另计。
3. 有远期时列卖出外币名义金额 Q，增加到期本币现金流 Q(F−E₁)。注明覆盖本金还是预计终值。
4. 用同期本币收益序列重估相关性和组合方差，报告样本期、市场压力时相关性变化、流动性与政治风险。

## B — 边界

当地无风险利率只锁定外币终值；汇率、资本管制、税费和撤资能力仍会改变本币所得。只有单期收益不足以估计相关系数。
