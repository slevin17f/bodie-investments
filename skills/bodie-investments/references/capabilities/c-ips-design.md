# 把投资者目标和现金需求写成可复核的 IPS

## R — 来源

第28章 28.1–28.7，印刷页960–983。

## I — 方法

先从负债、支出和时点推导风险承受能力，再与主观意愿、目标回报比较。把冲突写入政策，按职责与事件复核。

## A1 — 演算

合成演练。基金资产100，半年内必须支出25，无同期流入，另有长期支持项目。先将25及对应期限列为流动性需求，剩余75才进入长期政策讨论。若政策要求锁定90，将留下15的已知缺口。

## A2 — 调用条件

用于根据案例起草投资政策书，审阅计划能否满足责任、投资期限及提款。若只需测量管理人既有业绩，转业绩归因卡。

## E — 操作与输出

1. 识别委托人、受益人、基准币种、资产和负债。按期限列现金流表，区分必须与可推迟支出。
2. 明确收益目标的期间、名义/实际、费税口径。对照最大可承受损失、动用本金能力和主观意愿，若目标不可兼容，量化缺口并请委托方决定调整目标或资源。
3. 分别记录流动性、期限、税务、法律监管、独特限制。由已知约束推导最低流动储备、可投资集合、战略权重及允许区间；输入不足时保留待定项。
4. 指定政策基准、监测频率、超界处理、再平衡权限、重大现金流或负债变化的复核责任人。交付一页目标、约束、政策和治理表，加一条资金压力情景。

## B — 边界

不同辖区税法、监管及客户授权需另核实。高风险意愿不能抵消近期刚性提款，负债久期与赞助方承诺会影响养老金可承担风险。
