# 按管理责任衡量业绩并核对归因

## R — 来源

第24章 24.1–24.5，印刷页828、833、850–854。

## I — 方法

外部申赎可以改变投资者实际所得。先确定评价对象，再选择收益口径、风险分母以及事前政策基准。

## A1 — 演算

教材演算（印刷页851）。组合当月5.34%，中性政策组合3.97%，需解释1.37个百分点。用实际权重配置各指数构成中间组合，连接政策收益与实际收益。

## A2 — 调用条件

用于评价管理人、资金持有人或给定行业权重和收益的单期归因。外币先转换到同一评价币种。

## E — 操作与输出

1. 在外部资金流前后切分子期间，以 ∏(1+r_t)−1 求累计时间加权收益；投资者体验采用带日期、方向的现金流解净现值为零的内部收益率。
2. 独立组合每单位总风险用 Sharpe，同期平均超额收益除以同频超额收益标准差。已分散组合可考察 Treynor（超额收益/β），或相对指定市场模型的 Jensen α。明确基准、样本、费前费后。
3. 单期、权重完备时，基准收益 B=Σbᵢsᵢ，实际收益 P=Σwᵢrᵢ。计算配置贡献 Σ(wᵢ−bᵢ)sᵢ、选择贡献 Σwᵢ(rᵢ−sᵢ)，逐行业输出，两项之和须等于 P−B。该写法把交互项计入选择。
4. 报告结果和经济量级，样本短或择时改变风险时说明固定β比较的局限。

## B — 边界

资金流日期或流前估值缺失时标明估计。β接近零时 Treynor 比率不稳定。不要把单期逐行业贡献直接累计成多期几何收益。
