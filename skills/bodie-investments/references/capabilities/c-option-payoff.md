# 用到期现金流检查期权策略与看涨看跌平价

## R — 来源

第20章 20.2–20.4，尤其是式20.1（印刷页692）。

## I — 方法

将每一腿化成到期现金流，按执行价划分区间。相同到期现金流在无摩擦市场应具有相同初始价值。

## A1 — 演算

教材演算（印刷页692）。无股息股票110，一年期执行价105，看涨17、看跌5，无风险年利率5%。看涨加零息债成本117，股票加看跌成本115，两侧到期均为 max(105,S_T)，模型价差2。

## A2 — 调用条件

给出执行价、权利金和持仓方向时计算盈亏或核对同一标的两份欧式合约。若问仅一份合约理论价格且有涨跌两种状态，转二叉树。

## E — 操作与输出

1. 登记标的、到期、行权方式、股息、合约乘数与持仓数量，写明以每股还是每张计。
2. 到期看涨取 max(S_T−K,0)，看跌取 max(K−S_T,0)。卖方取负。股票腿加 S_T，按份数加总。按所有执行价分段，检查各拐点与最右侧斜率。
3. 各段减初始净支出得到常见的未计融资到期盈亏；若按终值衡量，扣除净支出的到期本利和。逐区间求盈亏平衡点并检查根是否落在区间。
4. 对同执行价、同到期、欧式、无股息组合，比较 C+PV(K) 与 P+S。给出两侧成本、差、到期两情形和所用报价。

## B — 边界

穿越除息日需处理期间股息。美式提前行权、不同到期或保证金与卖空限制都会影响可执行性。仅有中间价时只能报告模型差额。
