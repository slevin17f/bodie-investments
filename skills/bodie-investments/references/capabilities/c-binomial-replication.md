# 用二叉树复制期权并核对节点价值

## R — 来源

第21章 21.3，印刷页722–730。

## I — 方法

一股标的和无风险账户可在两个终点复制期权。复制组合的成本提供与实际涨跌概率无关的定价。

## A1 — 演算

教材演算（印刷页722–723）。S=100，终点120或90，K=110，无风险增长因子1.10。看涨支付10或0，Δ=1/3。借入30/1.10，复制成本100/3−30/1.10≈6.06。

## A2 — 调用条件

用于给出离散树、每步无风险利率与行权规则的教学任务。若给连续波动率与到期时间，可查连续模型。

## E — 操作与输出

1. 将利率换算为每步增长因子 R，核查无股息树 d<R<u。到期逐节点计算支付。
2. 令 q=(R−d)/(u−d)，回推 V=[qV_u+(1−q)V_d]/R。美式每一可行权节点再与立即行权价值比较取大。
3. 在继续持有节点求 Δ=(V_u−V_d)/(S_u−S_d)，无风险账户 B=(V_d−ΔS_d)/R。用 ΔS+B 检查当前值，并验证上下终点均复制。
4. 输出节点表、根节点价格与初始对冲数量。标明 q 为定价权重，期权乘数另计。

## B — 边界

u=d 无法解对冲系数，增长因子不在两分支之间则树与无套利前提冲突。现金股息、分段利率需要重建相应节点。
