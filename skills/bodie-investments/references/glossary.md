# 在计算前确认术语的口径

| 术语 | 计算或判读时要问什么 | 章 |
| --- | --- | --- |
| NAV 净资产值 | 基金资产减负债后除以流通份额。封闭式基金的成交价可偏离 NAV。 | 4 |
| HPR 持有期收益 | 买入到卖出的价格变化与期间收入都属于回报。标明该期间长度。 | 5 |
| 算术与几何平均 | 前者对单期观测取均值，后者对财富增长因子取连乘再开方。波动使两者分离。 | 5 |
| CAL 资本配置线 | 固定一个风险组合，改变它与无风险资产的混合权重。CML 特指以市场组合为风险组合的线。 | 6、9 |
| 有效前沿 | 在相同标准差下能提供最高期望收益的一组可行组合，须先声明权重约束。 | 7 |
| β 与残差风险 | β 度量对指定因子的敏感度，残差是模型未解释的波动。必须说明基准是谁。 | 8、9 |
| α | 在选定模型及样本下，超出模型要求回报的部分。点估计要和估计误差一起看。 | 8、13、24 |
| YTM 到期收益率 | 让承诺现金流现值等于全价的单一折现率。实际回报另受违约、再投资及出售价格影响。 | 14 |
| 即期与远期利率 | 即期利率从今天起计，隐含远期由对应期限的贴现因子推出。期限溢价会影响远期利率的解释。 | 15 |
| 麦考利与修正久期 | 前者是现值加权平均给付时间，后者用于估算收益率小幅变动时的价格变化率。要对齐复利频率。 | 16 |
| 内在价值与时间价值 | 期权按立即行权可获的正给付计内在价值，报价的其余部分为时间价值。注明行权制度。 | 20、21 |
| 基差 | 本书期货章节用现货价减期货价。跨资产、跨期限套保还需估计两者变化的关系。 | 22 |
| 信息比率 | 本书主动组合语境常用 α 除以残差标准差。若报告主动收益除以跟踪误差，要说明分子、分母和基准。 | 24、27 |
| 投资政策说明书（IPS） | 把回报目标、风险承受能力、现金需求、约束与复核安排写成可据以评价组合的条件。 | 28 |
