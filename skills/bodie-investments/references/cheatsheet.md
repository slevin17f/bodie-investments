# 决策规则速查 — Investments（投资学，第 13 版）

| 能力 | 一句话规则 |
|---|---|
| 重建基准权重与拆股后的指数点位 | 先把资产类别配置与类别内部选券分开。 |
| 复核成交价格、融资融券账户与追保线 | 买入要付卖价，立即卖出只能取买价。 |
| 比较基金净值、收费方式与持有期净回报 | 基金净值为单位持有人分担的净资产。 |
| 把历史收益、通胀与尾部损失换到同一口径 | 先问是估计下一期的平均收益、复原已实现财富路径，还是测量极端损失。 |
| 按风险厌恶与借贷约束分配风险组合 | 给定风险组合 P，先决定向它投入多少，剩余资金进入无风险资产。 |
| 用协方差求组合风险并区分最小方差与切点 | 风险由权重及资产间共同变化决定。 |
| 用单指数回归分解市场与残差风险 | 将资产超额收益向市场超额收益回归。 |
| 用 CAPM 必要收益检验给定预期收益 | 市场组合中一项资产的边际风险由它与市场的协方差决定。 |
| 按因子暴露复制组合并核查 APT 定价差 | 用可交易的因子组合复现目标的系统风险。 |
| 用事件窗口检验公告后的异常收益 | 公告效应要相对于同日正常收益衡量。 |
| 把行为解释转成可检验的假设 | 同一交易现象可能源于偏差，也可能源于合理风险补偿、约束或信息更新。 |
| 用两步回归审阅风险溢价证据 | 时间序列估计各资产对共同因子的敏感度，横截面检验这些暴露是否对应平均风险溢价。 |
| 按票息时点审阅债券价格和收益率 | 固定现金流债券的到期收益率是使承诺付款的现值等于全价的内部收益率。 |
| 从零息折现因子还原远期利率 | 现金流按各自到期日定价，同期限同币种同风险的零息折现因子可用于组合复制。 |
| 以久期、凸性和现值检查债务免疫 | 在小幅平行利率移动下，资产与负债的美元久期匹配可抵消净值的一阶变化。 |
| 把宏观冲击落实到行业利润 | 区分需求与供给冲击，再追踪销量、售价、可变成本、固定成本以及融资负担。 |
| 匹配股利、自由现金流与估值假设 | 权益价值由股东可得现金流决定。 |
| 用五因素杜邦分解定位 ROE 差异 | 把普通口径的净利润/权益拆为税负、利息负担、营业利润率、资产周转与权益乘数的乘积，能区分经营改善和融资改变。 |
| 用到期现金流检查期权策略与看涨看跌平价 | 将每一腿化成到期现金流，按执行价划分区间。 |
| 给无股息股票的欧式期权定价 | 在恒定利率、恒定波动率和可连续调整复制组合等假设下，欧式权利的模型价值取决于现价、行权价、期限、波动率及无风险利率。 |
| 用二叉树复制期权并核对节点价值 | 一股标的和无风险账户可在两个终点复制期权。 |
| 核算期货逐日盈亏与持有成本 | 期货盈亏由结算价变化、方向、张数与乘数决定。 |
| 按风险敞口核算期货套保及互换净额 | 先量化基础头寸对价格、汇率或利率单位冲击的现金变化，再用合约相反的现金变化进行抵消。 |
| 按管理责任衡量业绩并核对归因 | 外部申赎可以改变投资者实际所得。 |
| 按本币重算海外收益与分散效果 | 把外地资产的增长和汇率变动放在同一条现金流上。 |
| 按高水位和分配顺序还原另类基金净收益 | 私募现金流时点、估值频率和费用瀑布共同决定 LP 所得。 |
| 用一个带置信度的观点更新均衡风险溢价 | 先从市值权重反推与市场组合一致的基线溢价，再由预测误差决定观点能拉动多少。 |
| 用预测精度和残差风险分配主动权重 | 单指数模型把市场敞口交给基准，把经校准的异常收益相对残差风险的大小用于主动权重，再用主动组合的β校正配置。 |
| 把投资者目标和现金需求写成可复核的 IPS | 先从负债、支出和时点推导风险承受能力，再与主观意愿、目标回报比较。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
